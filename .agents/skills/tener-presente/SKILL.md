# Convenciones de estructura del proyecto

Al crear o modificar código en este proyecto:

1. Usa HTML5 y la última versión de Bootstrap para la estructura y los componentes de la interfaz.
2. Debe ser responsibe para computadores y celulares
3. La se trabajara como base un archivo  `index.html`, `index.js` y `style.css`
4. Coloca todos los estilos en `style.css`; no agregues estilos en línea ni bloques `<style>`.
5. Coloca todo el código JavaScript en `index.js`; no agregues JavaScript en línea ni bloques `<script>` con código.
6. Cuando te pida agregar o modficar iconos usa primeramente Bootstrap Icons, de no existir el icono pregunta que se debe
7. En `index.js` se debe comentar lo que hace el código
8. Debe tener temas de colores para mejor lectura
9. En caso de guardar datos , guarda en el localstorage y si no se puede pregunta que hacer
10. Debe tener un footer donde diga página hecha por Trigataro con el icono de github, el nombre y el icono deben abrir otra ventana hacia el link https://github.com/TriGataro
11. Guadar datos en el local storage, si es necesario
