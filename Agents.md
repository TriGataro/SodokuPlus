# Convenciones de estructura del proyecto

Al crear o modificar código en este proyecto:

1. Usa HTML5 y la última versión de phaser.js para la estructura y los componentes de la interfaz.
1. Debe ser responsive para computadores y celulares
1. La se trabajara como base un archivo  `index.html`, `style.css`
1. Coloca todos los estilos en `style.css`; no agregues estilos en línea ni bloques `<style>`.
1. Coloca todo el código TypeScript en una carpeta llamada  `JS` donde colocas los archivo `.js` y `.ts`; no agregues JavaScript en línea ni bloques `<script>` con código.
1. En  se debe comentar y factotizar en distintos archivo el codigo javascript y typescript lo que hace el código
1. Debe tener temas de colores para mejor lectura
1. En caso de guardar datos, guarda en el localstorage y si no se puede pregunta que hacer
1. Debe tener un footer donde diga página hecha por Trigataro con el icono de github, el nombre y el icono deben abrir otra ventana hacia el link https://github.com/TriGataro
1. Agregar .gitignore que ignore las carpetas y archivos ocultos, tambien ocultas las carpetas .agents
1. Debe tener un boton de compartir tanto para celulares como para computador
1. Debe tener botones para pausar y reiniciar y un boton de menú 
1. Debe tener un virtual joystck y botones virtuales para el celular , estos elementos deben estar a la izquierda y derecha de la pantalla de juego.
1. Pare el movimiento debe usar las fechas del teclado y las teclas W,A,S,D
2. Debe tener botones de pausa y de reinicio un un boton de menú
3. Se debe bloquear el seleccionar, copiar y pegar
4. Debe reconocer si se conectar un joystick si es posible
5. Desactiva el zoom por doble toque en toda la página y evita que iOS agrande el texto al girar
6. Agrega el logo https://github.com/TriGataro/PersonalProyects/blob/master/img/logo.png que ademas sea un link a https://trigataro.github.io/PersonalProyects/
